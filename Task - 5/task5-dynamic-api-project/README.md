# Task 5 — Dynamic JavaScript DOM Logic & RESTful API Client

A responsive product catalogue built with HTML, CSS, JavaScript ES modules, and the FakeStore public REST API.

## Features
- `async/await` API requests in `api.js`
- Real-time search across product title, description, and category
- Category filtering and sorting by price, rating, and name
- Saved search/filter/sort preferences using `localStorage`
- Loading skeletons, error messages, retry button, and empty results state
- Responsive CSS Grid/Flexbox layout for mobile, tablet, and desktop
- Accessible labels, status text, and reduced-motion support

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Run `index.html` using the **Live Server** extension. Because the project uses JavaScript modules, use a local server rather than opening the file directly.
4. Keep an internet connection available for the API request.

API: https://fakestoreapi.com/products

## Files
- `index.html` — page structure
- `style.css` — responsive design and loading states
- `api.js` — API request and error handling
- `app.js` — DOM rendering, search, filtering, sorting, and local storage
